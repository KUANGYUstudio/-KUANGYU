01 / TRAINING LOAD

訓練負荷分析

6 個主題

了解每堂課帶來多少負荷、近期與長期負荷如何變化，以及如何把數字放在一起判讀。

TSS｜單次訓練負荷

理解單堂訓練的負荷量化方式，以及不同運動項目 TSS 的差異。

學習重點

訓練時間、相對強度、單堂負荷；理解 TSS 是模型估算，不是直接測量身體疲勞。

IF｜強度係數

了解單堂訓練相對於個人閾值的強度。

學習重點

IF 與閾值設定、訓練時間及 TSS 的關係；確認閾值設定是否合理。

CTL｜長期訓練負荷

觀察長期訓練負荷的累積與變化。

學習重點

42 天加權平均的概念、長期趨勢，以及 CTL 不等於直接測得的體能或比賽能力。

ATL｜近期訓練負荷

觀察近期訓練刺激與負荷變化。

學習重點

7 天加權平均、近期負荷波動，以及 ATL 上升與實際疲勞感受之間的差別。

TSB｜訓練負荷平衡

理解近期負荷相對於長期負荷的差距。

學習重點

TSB 的日期計算方式、正負值的意義，以及為什麼不能把單一數值當成恢復或安全判定。

Ramp Rate｜CTL 負荷爬升率

觀察 CTL 每週增加或下降的速度。

學習重點

不同 CTL 基礎下的變化解讀、與 ATL／TSB 串聯，以及避免把 Ramp Rate 當成傷病預測值。

02 / PERFORMANCE

運動表現與生理反應

5 個主題

從心率、配速、功率與乳酸反應，判斷運動員是否真的產生訓練適應。

Cardiac Drift｜心率漂移

觀察固定輸出下，心率是否隨運動時間逐漸上升。

學習重點

心率與配速／功率的解耦、長時間有氧運動反應，以及熱環境、補水、疲勞等干擾因素。

Pace / Power Efficiency｜配速與功率效率

比較相同心率下的輸出，或相同輸出下的心率反應。

學習重點

配速、功率、心率與主觀用力的交叉比較；控制地形、天氣、設備與測試條件。

Lactate / LT｜血乳酸與乳酸閾值

理解乳酸反應、LT1／LT2 與持續運動能力。

學習重點

乳酸測試的階段設計、閾值判讀方法、測試限制，以及閾值配速／心率的應用。

VO₂max｜最大攝氧量

認識最大攝氧量及其在耐力表現中的角色。

學習重點

VO₂max、閾值與運動經濟性之間的關係；理解單一 VO₂max 數值不能完整代表耐力表現。

Training Zones｜訓練強度區間

把閾值、心率、配速或功率轉換成可執行的訓練強度。

學習重點

不同分區模型的差異、區間依據、個人化設定與定期重新校準。

03 / RECOVERY & WELLNESS

疲勞、恢復與主觀監控

8 個主題

整合穿戴裝置的生理數據、睡眠與選手主觀回饋，理解每天的狀態與長期恢復趨勢。

HRV｜心率變異度

追蹤個人 HRV 基準與日常波動，不以單日數字定論。

學習重點

HRV 的基本概念、測量一致性、個人基準、趨勢觀察，以及與睡眠、壓力和訓練反應一起判讀。

Resting HR｜靜息心率

觀察休息狀態心率相對於個人基準的變化。

學習重點

固定測量條件、個人基準、持續偏離與可能干擾因素；避免單次讀值過度解讀。

Sleep｜睡眠時間與結構

理解總睡眠時間、深層睡眠、淺層睡眠、REM 與夜間清醒時間。

學習重點

優先看總睡眠時間與規律性，再把睡眠階段當作輔助資訊；理解穿戴裝置對睡眠階段的估算限制。

Body Battery｜身體能量指數

認識 Garmin 如何整合生理訊號估算身體能量變化。

學習重點

理解 5–100 分數的常見區間、日內回升與消耗，以及它不是直接測量的能量或恢復程度。

Stress Level｜生理壓力指數

理解 Garmin 壓力分數與休息、低、中、高壓力分類。

學習重點

了解 HRV 等生理訊號、活動與生活因素的影響；區分生理壓力估算與心理壓力量表。

Recovery Monitoring｜恢復監控整合判讀

把 HRV、RHR、睡眠、Body Battery、Stress 與主觀回饋放在一起。

學習重點

建立個人基準、觀察變化持續時間、交叉驗證多項指標，並結合 RPE、精神、痠痛與訓練表現形成教練判讀。

RPE / Session RPE｜主觀用力程度

學習如何讓學員回報單堂訓練感受，並與課表負荷對照。

學習重點

RPE 量表、Session RPE 的回報時機與計算概念、不同運動項目的使用方式，以及如何降低學員填寫偏差。

Wellness｜每日身體狀態

把睡眠、疲勞、痠痛、情緒與壓力變成簡單可追蹤的回饋。

學習重點

問卷題目設計、固定回報時間、個人趨勢、隱私與回報負擔；避免把主觀分數當成診斷。

04 / LOAD DISTRIBUTION

訓練分配與負荷結構

3 個主題

不只看總負荷，也要看負荷如何分布在一週與不同強度之間。

Intensity Distribution｜強度分布

分析低、中、高強度訓練時間或訓練量的比例。

學習重點

不同強度分布模型、三項運動的差異，以及如何將分布與選手目標、訓練階段連結。

Monotony｜訓練單調性

觀察每日負荷是否過於相似，缺少負荷變化。

學習重點

每日負荷變異、週內安排與指標限制；不將單調性單獨視為傷病或過度訓練判定。

Strain｜訓練壓力累積

理解訓練總量與負荷分布特性如何一起影響週期壓力。

學習重點

Strain 與 Monotony 的常見概念、計算假設及使用限制；與 CTL／ATL 等模型區分。

05 / MOVEMENT & BIOMECHANICS

動作與生物力學評估

3 個主題

把動作品質、專項技術與疲勞後的變化納入教練觀察，不只依賴訓練平台數字。

Running Gait｜跑步步態

觀察步頻、步幅、觸地時間與跑姿在不同速度下的變化。

學習重點

步態觀察的情境與限制、速度影響、疲勞前後比較，以及不把單一跑姿特徵當成傷病診斷。

Movement Assessment｜動作控制

評估單腳控制、關節活動、穩定性與動作協調。

學習重點

動作測試的標準化、左右差異、任務需求、疲勞影響，以及如何把評估結果轉成訓練內容。

Cycling Biomechanics｜自行車生物力學

理解踩踏、踏頻、騎乘姿勢與左右輸出資訊。

學習重點

功率與踏頻的關係、左右平衡數據的限制、車架設定與騎乘姿勢的觀察。

06 / TESTING & CALIBRATION

能力測試與數據校準

5 個主題

確認數據來源、測試條件與強度區間可靠，避免用過期或不準確的設定安排課表。

FTP Test｜自行車功能性閾值功率

理解 FTP 測試方式、估算限制與功率區間設定。

學習重點

測試協定、配速策略、測試重複性、FTP 更新與不同測試方法的差異。

CSS Test｜游泳臨界配速

透過游泳測試估算可持續速度並設定訓練配速。

學習重點

常見測試距離、計算方式、技術與池長影響，以及如何用 CSS 安排間歇。

Field Test｜實地能力測試

設計可重複、可比較的戶外測試流程。

學習重點

路線、環境、設備、熱身、測試流程與結果紀錄標準化。

VO₂max Test｜最大攝氧量測試

認識實驗室或可用設備進行的最大攝氧量評估。

學習重點

測試流程、氣體分析概念、結果解讀及測試資格與安全限制。

Data Quality｜資料品質與區間校準

確認心率、GPS、功率計、閾值與訓練區間設定可信。

學習重點

感測器異常、校正、資料缺漏、測試條件一致性與定期更新個人閾值。

07 / PROGRAM DESIGN

課表設計與訓練週期

6 個主題

把訓練原則、單堂課表、每週安排、訓練階段與年度賽季計畫串連起來。

Training Principles｜訓練原則

理解特異性、漸進超負荷、個別化、恢復與可持續性。

學習重點

從運動員目標、訓練史、能力與生活條件設定可執行的訓練方向。

Workout Design｜單堂課表設計

設計熱身、主課表、強度、組數、休息與收操。

學習重點

Easy、Tempo、Threshold、Interval、Long Session 等課型的目的與處方要素。

Weekly Scheduling｜每週訓練安排

安排頻率、強弱日、長課、休息日與三項運動分配。

學習重點

訓練量、強度、頻率與恢復的互動；游泳、自行車、跑步的負荷整合。

Periodization｜週期化與賽季規劃

把 Base、Build、Recovery、Peak、Taper 串成賽季計畫。

學習重點

年度訓練計畫、比賽優先順序、訓練區塊、恢復安排與賽前減量。

Training Cycle｜訓練階段與週期

理解 Base、Build、Recovery、Peak 與 Taper 等階段的目的與銜接。

學習重點

辨識各階段的訓練目標、負荷安排、恢復需求與進入下一階段的依據。

ATP｜年度訓練計畫

把賽事目標、重要比賽與訓練區塊安排到年度時間軸。

學習重點

學習賽事優先順序、年度週期、訓練區塊、測試節點、恢復週與賽前減量的整體規劃。

08 / COACHING DECISIONS

監控、回饋與教練決策

3 個主題

將訓練數據、身體回饋與表現放在一起，練習案例分析並決定課表是否維持或調整。

Integrated Monitoring｜整合監控

串聯負荷、恢復、表現與動作品質，避免只看單一數字。

學習重點

建立個人基準、觀察趨勢、辨識訊號不一致，以及區分事實、假設與教練決策。

Program Adjustment｜課表調整與追蹤

依照訓練反應，決定維持、增加、降低或重新安排刺激。

學習重點

追蹤課表完成率、表現變化、RPE／Wellness、恢復狀態與下一次訓練的調整理由。

Case Analysis｜教練案例分析

練習從真實訓練紀錄辨識問題、整合證據並提出可追蹤的決策。

學習重點

依序整理選手背景、訓練負荷、恢復指標、主觀回饋與表現；區分觀察事實、可能解釋與待確認資訊，最後提出調整理由與追蹤方式。
